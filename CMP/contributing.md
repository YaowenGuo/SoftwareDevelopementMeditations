# 贡献代码

1. 按照这里的文档设置开发环境和下载代码：https://android.googlesource.com/platform/frameworks/support/+/androidx-main/docs/onboarding.md

2. bug 列表：https://issuetracker.google.com/issues?q=status:open%20componentid:612128&s=created_time:desc

3. 只有runtime 能通过 github 贡献，其它需要走 google 开源仓库贡献流程。

4. CMP bug 列表：https://youtrack.jetbrains.com/projects/CMP

5. CMP 代码贡献，直接使用 github fork, pull request 贡献。
