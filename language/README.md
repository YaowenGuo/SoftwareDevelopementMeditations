# CodingLanguage

纵观几个主流语言，其核心无外乎数据组织 + 处理流程，正是对应着数据结构 + 算法。其它语言也逃不出这个框架，因为编程语言设计出来就是用来处理数据的，而其处理过程就是算法。

数据组织的形式有：简单数据类型，数组，结构体，共用体，类，对象。
处理过程有：顺序，分支，循环。

虽然本质上都一样，由于不同语言受时代的编程思想和作者偏好，实现手法等影响，其表线形式却各有不同。是否符合人的使用习惯和思维方式，确实影响到用户的使用和程序设计的质量。就是人们直观感受的：是不是一门优雅的语言。其实，每一门语言都不乏大神级的人物，能够使用该语言设计出优秀的函数库或软件。但是优秀的语言能够加快开服速度和帮助提高软件质量。


C、Rust、Python、Kotlin 语言的语法对比和语言特性。


## 编程模式

- 命令式编程
- 面向对象编程
- 函数式编程

随着实践的丰富、现代语言都不再执着于对固定编程范式，而是对多种范式都能支持，由开发者结合实际需求做出最佳的选择。

对象编程：面向对象编程的一个执着点是一切皆对象。Java 嫌 C++ 不够全是对象，让 main 函数也得定义到类中，奇怪的写法解释为一切皆对象，函数必须写在类里。Kotlin 嫌 Java 不够一切皆对象，方法和静态变量不是对象。我们不禁要问：世界是对象的吗？OOP 只唯一解决方法吗？如果不是执着于一切皆对象是不是只会写出蹩脚的答案？
