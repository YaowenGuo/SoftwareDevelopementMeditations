# 并发安全

## 什么是并发安全？

并发安全是指在多线程环境下，程序能够正确地执行，不会出现数据不一致或死锁等问题。

数据竞争（Data Race）‌：多个线程同时读写同一共享变量，且至少有一个是写操作，若未加同步控制，则可能产生错误结果。
‌可见性问题‌：一个线程修改了共享变量，其他线程可能看不到最新值（因 CPU 缓存、指令重排序等）。
‌原子性缺失‌：看似单一的操作（如 count++）实际由多个步骤组成（读 → 加 → 写），若中间被其他线程打断，会导致结果错误。

## 安全出现在哪些地方？

多线程
进程：
    共享内存
    多个进程同时写同一个文件时
    数据库操作、网络端口/硬件资源
