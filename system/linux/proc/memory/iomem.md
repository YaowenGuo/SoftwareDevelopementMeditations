# iomem

系统物理地址空间的完整布局和分配情况。
格式为：起始地址-结束地址 : 设备描述

Reserved：保留区域，通常用于系统硬件的特殊用途，硬件设备的寄存器空间，
System RAM ：系统可以使用这些内存地址来存储数据和代码，可用内存，DDR内存的物理地址的主要体现。
其他：用于指定模块的内存。
常见的设备名称：
外设控制器：
- i2c：I2C总线控制器
- dma_per： DMA控制器
- spi： SPI控制器

存储设备接口：
- sdhc：存储卡、eMMC等存储设备的接口控制器

系统功能模块：
- ax_hrtimer：高精度定时器
- watchdog：看门狗定时器
- audio_codec：音频编解码器

内核内存管理：
- System RAM：主系统内存
- Kernel code： 内核代码段
- Kernel data： 内核数据段

地址空间被合理划分为：
- 低地址区（0x1A00000以下）：外设控制器
- 中地址区（0x40000000附近）：内核空间
- 高地址区（0x44F00000以上）：系统内存扩展


附加说明：

/proc/dma 和 /proc/iomem 都是Linux内核提供的虚拟文件，用于展示系统资源分配情况，但它们的用途和存在条件有所不同。

[1]./proc/dma 文件

/proc/dma 文件列出由驱动程序保留的DMA通道和保留它们的驱动程序名称。该文件主要用于ISA总线的DMA通道管理，显示当前正在使用的DMA通道分配情况。例如，常见的输出可能包含"4: cascade"，表示DMA通道4被级联控制器使用。


问题：为什么有的系统没有/proc/dma？

现代系统主要使用PCI/PCIe总线，这些总线采用内存映射方式（MMIO）而非传统的DMA通道，ISA总线已逐渐被淘汰，因此在新架构的系统上可能看不到该文件，如果系统没有ISA设备或相关驱动程序，该文件可能为空或不存在。


[2]./proc/iomem 文件

/proc/iomem 文件记录整个系统物理地址空间的分配情况，包括RAM、设备寄存器、PCI设备内存映射等。它显示每个物理设备在系统内存中的映射信息，采用树状结构展示。


[3].两者之间的关系

虽然两者都涉及系统资源管理，但作用范围不同：

/proc/dma：专门管理ISA DMA通道，已逐渐被淘汰

/proc/iomem：管理整个物理地址空间，包括DMA缓冲区、设备寄存器等，

现代系统普遍采用内存映射I/O（MMIO）方式访问设备,所有设备（包括PCI、USB、网络设备等）都需要在物理地址空间分配资源, 是现代系统的主要资源管理方式。
