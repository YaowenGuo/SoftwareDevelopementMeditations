# 给入门人员的一点建议

1. 数据结构和算法


2. 培养抽象思维


3. 寻找一个模型


4. 拆分、构建、解析



核心思想：

- 代码内聚：同一功能所有逻辑尽量写在一起而不是分散在各个模块、一个类、一个文件、一个 Util。代码之间的链接越少越好。

  - 例如字体大小修改在练习和设置里两个模块都有，好的方式是将代码都集中在一起，比如设置模块里，只需要在做题里调用就好。

  - 另一个例子是老师欢迎语。在首页也有播放逻辑，我们希望这些逻辑能和欢迎语的逻辑在一起。在首页只需要调用一个函数就行，而不是也写一大段播放代码。

  - 合理的划分组织也能提高内聚。将关联性更高的代码封装在一个类里，而不是交织在一起。例如面试里有个每个几秒采集一张用户的视频帧给用户生成集锦的断视频的功能。很容易写成一个 UserVideoComp 完成所有逻辑。但仔细分析这个过程包含了
    - 采样逻辑。
    - 文件存储
    - 图片合成视频
    - 上传的逻辑
  将这些单独封装成函数。这些组件就能形成数据流的形式拼装。文件->合成视频->上传。其中文件、合成视频、上传逻辑可以在其它
